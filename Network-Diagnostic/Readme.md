# Network Diagnostic Toolkit

## Deskripsi
Script untuk troubleshooting jaringan Windows.

## Tujuan
Membantu IT Support melakukan pengecekan dasar koneksi jaringan Windows secara otomatis.

## Fitur
- Cek IP Address
- Cek Default Gateway
- Ping Gateway
- Ping Internet
- Cek DNS

## Teknologi
- PowerShell
- Windows PowerShell Networking

## Cara Menjalankan
1. Buka PowerShell.

2. Masuk ke folder project.

3. Jalankan script:
command = ".\NetworkDiagnostic.ps1"
