# Portofolio IT Support

Kumpulan project IT Support berbasis PowerShell yang dibuat untuk membantu proses troubleshooting dan diagnosis komputer Windows secara otomatis.

## Project

### 1. Network Diagnostic Toolkit

Tool PowerShell untuk melakukan pemeriksaan dasar koneksi jaringan pada Windows.

Fitur:

- Mengecek network adapter
- Mengecek IP Address
- Mengecek Default Gateway
- Menguji koneksi ke Gateway
- Menguji koneksi Internet
- Mengecek DNS
- Memberikan diagnosis dasar

[ Lihat Project ](./network-diagnostic-toolkit/)

---

### 2. Software Diagnostic Toolkit

Tool PowerShell untuk melakukan pemeriksaan dasar aplikasi, service, dan resource komputer Windows.

Fitur:

- Mengecek aplikasi yang dibutuhkan
- Mengecek status aplikasi
- Mengecek Windows Service
- Mengecek penggunaan CPU
- Mengecek penggunaan Memory
- Mengecek ruang penyimpanan
- Validasi konfigurasi
- Diagnosis otomatis
- Membuat diagnostic report

[ Lihat Project ](./software-diagnostic-toolkit/)

## Teknologi

- PowerShell
- Windows

## Tujuan

Project ini dibuat untuk menunjukkan kemampuan praktis dalam bidang IT Support, troubleshooting Windows, dan automasi menggunakan PowerShell.
